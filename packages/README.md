# Packages

`packages/` is reserved for normal app/vendor package space.

Galerina language, runtime, target, tooling and domain packages now live in
`packages-ts/`.

Do not add Galerina package contracts here. Use this directory only when the host app
needs ordinary ecosystem packages that are not part of the Galerina package
collection.

`packages/fungi/memory/` holds hand-written .fungi memory code (scaffold only) — PENDING OWNER APPROVAL (Phillip); see `packages/fungi/memory/README.md`.
