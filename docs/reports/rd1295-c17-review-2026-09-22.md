Owner: RD-1295 / [C21](../BLOCKER-CHAPTERS-NON-EVIDENCE-2026-09-21.md#blocker-c21).
Source: `packages-ts/galerina-tower-citizen/src/load-graph.ts:137,153-199`.

Two controlled fixtures reproduce false-green closed sets:

1. An export condition object lists `node` before `import`. Node loads
   node.js, but the walker's fixed condition priority selects import.js.
   A closed set containing only import.js passes.
2. The importing package exports its own name while a nested node_modules
   package has the same name. Node uses the self-reference; the walker
   selects the nested package. Its allowed set excludes the real target.

Required outcome: runtime-equivalent resolution or explicit refusal for
unsupported cases, with positive and hostile tests against actual Node
resolution. Never admit an allow-list omitting the runtime target.
These probes do not establish that the current compiler loads inference.
Installed dependencies and modules loaded at runtime remain different sets.

## F2 — Historical special-name loss; demonstrated cases repaired
